# Internet.old

機能はそのまま、全てのサイトの見た目を90年代風に変えるChrome/Edge拡張機能です。

## 導入

1. chrome://extensions (Edgeは edge://extensions) を開きます
2. デベロッパーモードを有効にします
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選びます

## 使い方

ツールバーのアイコンを押すと、2つのスイッチが出ます。上が全体のオンとオフ、下が今見ているサイトのオンとオフです。オフにしたサイトには何も起きません。

## 変わるもの

背景色、文字色、リンクの色、書体、枠線、ボタンや入力欄の見た目、スクロールバーが変わります。角丸と影とアニメーションはなくなります。

## 変わらないもの

要素の位置と大きさは変わりません。ボタンは押せますし、フォームも送信できます。ページの中身そのものには手を加えません。

## 適用しない画面

reCAPTCHA、Cloudflare Turnstile、hCaptchaの認証画面と、主要な決済およびサインインの画面には適用しません。

## ビルド

```
./build.ps1
```

buildフォルダにzipができます。
